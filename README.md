# Tiempo de Ver

Calculadora estática y mobile-first para saber cuánto tardarás en terminar una serie, anime o saga, con o sin fecha límite.

## Qué incluye

- 100 planes editoriales preconfigurados entre series, anime y sagas cinematográficas.
- Modo manual por episodios totales o temporadas × episodios, y modo para películas.
- Cálculo por días reales de la semana, minutos disponibles y velocidad de reproducción.
- URL compartible y tarjeta vertical 9:16 descargable.
- Sin cuenta y con Google Analytics opcional, cargado únicamente tras consentimiento.
- Preparación técnica para AdSense: identificación de editor, `ads.txt` y páginas legales; sin anuncios activos todavía.

El sitio publicado se genera directamente desde `dist/`.
