# Binge Deadline

Calculadora estática y mobile-first para saber si puedes terminar una serie, anime o saga antes de una fecha concreta.

## Qué incluye

- 52 planes editoriales preconfigurados entre series, anime y sagas cinematográficas.
- Modo manual por episodios totales o temporadas × episodios, y modo para películas.
- Cálculo por días reales de la semana, minutos disponibles y velocidad de reproducción.
- URL compartible y tarjeta vertical 9:16 descargable.
- Sin cuenta, cookies publicitarias, Analytics ni AdSense.

El sitio publicado se genera directamente desde `dist/`.
